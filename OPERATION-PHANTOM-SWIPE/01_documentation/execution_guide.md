# Execution guide
Run all commands from the repository root using Python 3.10+.

1. `py generate_evidence.py`
2. `py 03_evidence_acquisition/acquisition.py`
3. `py 03_evidence_acquisition/generate_hashes.py`
4. `py 03_evidence_acquisition/verify_hashes.py`
5. `py 04_forensic_analysis/string_search.py`
6. `py 04_forensic_analysis/metadata_extraction.py`
7. `py 04_forensic_analysis/email_extraction.py`
8. `py 04_forensic_analysis/artifact_extraction.py`
9. `py 05_cryptography/create_test_archive.py`
10. `py 05_cryptography/password_cracker.py`
11. `py 06_reports/create_report.py`

The scripts are safe, local demonstrations over this project's own dummy files. Capture genuine screenshots of your own run in `07_screenshots/`.
