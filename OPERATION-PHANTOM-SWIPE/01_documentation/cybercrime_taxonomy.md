# Cybercrime taxonomy
- **ATM skimming:** hypothetical unauthorized capture of payment-card data at an ATM.
- **Card-data theft:** unauthorized obtaining or copying of payment-card information.
- **Card cloning:** creating a counterfeit payment instrument using copied data.
- **Identity/data theft:** misuse of identifying information.
- **Online payment fraud:** deceptive or unauthorized electronic payment activity.

This project models indicators only; it does not implement skimming, cloning, payment processing or unauthorized access.
