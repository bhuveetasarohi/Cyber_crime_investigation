# Investigation Workflow

Define investigation scope and patient-safety priorities.

Document the crime scene and assign evidence IDs.

Generate simulated hospital records, logs, and network data.

Run and analyze the safe ransomware simulator.

Acquire a forensic image of the simulated server data.

Calculate and verify SHA-256 hashes.

Complete evidence inventory and Chain of Custody forms.

Analyze logs, identify IOCs, and create an attack timeline.

Prepare the final forensic investigation report and recommendations.

Capture screenshots and upload the project to GitHub with automated validation.
