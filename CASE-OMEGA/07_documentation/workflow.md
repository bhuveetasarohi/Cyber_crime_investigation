# Investigation Workflow

1. Establish authority, scope, and patient-safety priorities.
2. Document the simulated scene and assign evidence IDs.
3. Generate fictional hospital records and logs.
4. Run the safe simulator; preserve source records and inspect encrypted copies.
5. Acquire a logical TAR package of the fictional server directory.
6. Calculate SHA-256 and compare with the manifest.
7. Correlate synthetic system, login, network, and USB records.
8. Review the generated timeline and IOCs.
9. Complete the report, limitations, and recommendations.
10. Capture genuine screenshots from your own run and commit the reviewed project.

## Reproducibility
Run commands from the repository root. The generator can be rerun to restore the synthetic scenario. The simulator creates a fresh training key and encrypted copies; keep the key private to the lab and do not upload it to a public repository if you extend the project with real data.
