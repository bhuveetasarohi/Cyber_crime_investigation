# Tools Used

| Tool | Purpose | Notes |
|---|---|---|
| Python 3 | Automation and analysis | Scripts run locally |
| SHA-256 (`hashlib`) | Integrity checks | Standard-library implementation |
| TAR (`tarfile`) | Logical evidence package | Not a physical disk image |
| Pandas | Optional tabular analysis | Dashboard/report extensions |
| Matplotlib | Timeline visualization | PNG output |
| Streamlit | Investigation dashboard | Local-only dashboard |
| Cryptography (Fernet) | Encrypt copies of dummy files | Safe simulator; originals preserved |
| FTK Imager | Optional real forensic acquisition lab | Use only on authorized test media |
| Git/GitHub | Version control and submission | Do not commit real patient data or secrets |
